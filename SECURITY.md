# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security issue in this repository, please report it responsibly:

1. Open a confidential report via **GitHub Private Vulnerability Reporting** under the Security tab of this repository.
2. Alternatively, contact the maintainer via GitHub profile contact information.
3. Please include reproduction steps, environment details, and expected impact.

Please do not open public issues for sensitive security vulnerabilities until they have been addressed.
